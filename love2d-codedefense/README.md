# love2d-codedefense

LÖVE (Love2D) 11.5로 만드는 코딩 교육용 타워디펜스 《Code Defense》입니다. 게임 내 코드
에디터에 Lua로 `on_tick(self, world)` 함수를 작성해 타워를 조종하고, 위에서 내려오는 밈
몬스터(버그/널 포인터/concat-nil)로부터 서버를 지킵니다.

## 요구 사항

- [LÖVE 11.5](https://love2d.org/) — `winget install love` 로 설치 가능

## 실행

```powershell
cd love2d-codedefense
& "C:\Program Files\LOVE\lovec.exe" .
```

## 조작

### 준비 화면 (배치 + 코드 작성)

| 키 | 동작 |
|----|------|
| ← → ↑ ↓ | 그리드 배치 커서 이동 (에디터 포커스 시에는 텍스트 커서 이동) |
| B | 커서 위치에 타워 건설 |
| T | 건설할 타워 종류 순환 선택 |
| Space | (버튼 모드 스테이지 한정) 타겟팅 전략 순환 변경 |
| Tab | 그리드 ↔ 코드 에디터 포커스 전환 |
| F1 ~ F4 | 코드 스니펫 퀵바 (on_tick 뼈대 / 공격 / if / for 삽입) |
| F5 | 전투 시작 (코드 오류가 있으면 시작을 막고 오류 위치 표시) |
| ESC | 스테이지 선택으로 나가기 |

### 전투 화면

| 키 | 동작 |
|----|------|
| 1 / 2 / 4 | 배속 x1 / x2 / x4 |
| ESC | 스테이지 선택으로 나가기 |

전투는 스테이지에 설정된 `pause_at` 시점마다 자동으로 멈추고 준비 화면으로 돌아가 코드를
다시 다듬을 기회를 줍니다. 타이틀/스테이지 선택 화면은 ↑↓로 이동, Enter로 확정, ESC로
뒤로 갑니다.

## 스테이지 구성

| # | 개념 | 방식 | 예산 | 보상 |
|---|------|------|------|------|
| 1 | 첫 타워 | 버튼(전략 프리셋 선택) | 200 | - |
| 2 | 전략 바꾸기 | 버튼(전략 프리셋 선택) | 200 | - |
| 3 | 따라 치기 | 코드 힌트(정답 그대로 옮겨 적기) | 220 | - |
| 4 | 빈칸 채우기 | 코드 힌트(빈칸만 채우기) | 220 | 캐시 (`cache.get/set`) |
| 5 | 변수 | 자유 코딩 | 240 | - |
| 6 | 조건문 | 자유 코딩 | 260 | 웹훅 (`on_spawn` 핸들러) |
| 7 | 반복문 | 자유 코딩 | 280 | - |
| 8 | 함수 | 자유 코딩 | 300 | - |

1~2 스테이지는 코드를 직접 노출하지 않는 버튼(전략 프리셋) 방식으로 시작하고, 3~4는 정답
코드를 따라 치거나 빈칸을 채우는 힌트 방식, 5~8은 변수 → 조건문 → 반복문 → 함수 순서로
난이도를 올리며 완전히 자유롭게 코드를 작성합니다. 각 스테이지는 클리어 시 다음 스테이지의
잠금이 해제됩니다.
