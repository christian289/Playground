# love2d-codedefense

LÖVE (Love2D) 11.5로 만드는 코딩 교육용 타워디펜스 《Code Defense》입니다. 준비 시간 없이,
카운트다운이 끝나는 순간부터 서버가 뚫릴 때까지 **실시간으로 계속 흐르는 전투** 속에서 게임 내
코드 에디터에 Lua로 `on_tick(self, world)`와 `build(type, r, c, name)`을 작성해 타워를 조종하고,
위에서 내려오는 밈 몬스터(버그/널 포인터/concat-nil)로부터 서버를 지킵니다.

## 세계관

모두가 매일 쓰는 서비스. 하지만 그것이 어디서, 누구의 손으로 돌아가는지는 아무도 모릅니다.
화려한 지상의 서비스 화면 뒤, 보이지 않는 지하 서버실에는 새벽 세 시에도 자리를 지키는 개발자
한 명이 있습니다. 버그(bug)·널 포인터(null-ptr)·concat-nil 같은 밈 몬스터들이 예고 없이
장애를 일으키고, 그는 오직 코드 하나로 서버를 지켜냅니다. 첫 실행 시 이 이야기를 4장면 컷신으로
보여주며(이후에도 타이틀의 "세계관" 메뉴로 다시 볼 수 있음), 클리어/패배 후 결과 화면에도 짧은
여운 문구가 남습니다.

## 요구 사항

- [LÖVE 11.5](https://love2d.org/) — `winget install love` 로 설치 가능

## 실행

```powershell
cd love2d-codedefense
& "C:\Program Files\LOVE\lovec.exe" .
```

## 조작

### 전투 화면 (배치 + 코드 작성 + 실시간 전투가 한 화면에서 동시에 진행)

| 키 | 동작 |
|----|------|
| F5 | 에디터의 코드를 저장하고 즉시 반영(최상위 재실행 + `on_tick` 교체). 문법/실행 오류가 있으면 기존 코드를 그대로 유지하고 화면에 빨간 오류 메시지를 표시 |
| F1 ~ F4 | 코드 스니펫 퀵바 (`build` 뼈대 / `on_tick` 뼈대 / 공격 / if 삽입) |
| Ctrl+1 / Ctrl+2 / Ctrl+4 | 배속 x1 / x2 / x4 |
| Ctrl+I | 문제 브리핑 카드 열기/닫기 (카운트다운 중엔 자동으로 열려 있음) |
| 숫자키 (1~2 스테이지 한정) | 버튼 스테이지에서 해당 버튼의 코드를 자동 타이핑·자동 저장 |
| ESC | 스테이지 선택으로 나가기 |

타워를 짓는 방법은 코드 안에서 호출하는 `build("타워종류", 행, 열, "이름")` 하나뿐입니다(같은
이름이 이미 있으면 아무 일도 하지 않는 멱등 동작). 그리드/코드 에디터 포커스 전환이나 방향키
건설 같은 별도 조작은 없습니다 — 이전에 있던 Tab/B/T/Space 조작은 삭제되었습니다.

### 마우스 조작

키보드 조작 대부분에는 마우스로도 동일하게 접근할 수 있습니다.

| 화면 | 마우스 동작 |
|------|------------|
| 타이틀 | 메뉴 항목에 마우스를 올리면 하이라이트, 좌클릭으로 확정 |
| 인트로 컷신 | 좌클릭으로 다음 장면(타이핑 중이면 즉시 완성) |
| 결과 화면 | 좌클릭으로 스테이지 선택으로 복귀 |
| 전투 화면(에디터) | 코드에 쓰인 `build`나 내가 정의한 함수 이름을 좌클릭하면 함수 사전 카드가 펼쳐짐(재클릭 시 접힘) |
| 전투 화면(정보 칼럼) | 함수 사전 목록의 함수명을 좌클릭해도 같은 방식으로 펼침/접힘 |

타이틀 화면은 ↑↓(또는 마우스 호버)로 메뉴(게임 시작 / 세계관 / 도감 / 종료)를 이동하고
Enter(또는 좌클릭)로 확정합니다. "세계관"을 고르면 오프닝 컷신을 다시 볼 수 있고, "도감"을
고르면 지금까지 마주친 타워·몬스터·내가 정의한 함수의 정보 카드를 볼 수 있습니다(←/→로 3개
탭 전환, ↑↓로 목록 이동, ESC로 타이틀 복귀). 컷신 재생 중에는 **Enter**(또는 좌클릭)로
다음(타이핑이 끝나기 전이면 즉시 완성), **ESC**로 전체 건너뛰기가 됩니다. 스테이지 선택/결과
화면도 ↑↓ 이동, Enter(또는 좌클릭) 확정, ESC로 뒤로 가는 동일한 규칙을 따릅니다.

## 게임 흐름

1. 스테이지에 입장하면 곧바로 **카운트다운**(스테이지별 15~30초)이 시작됩니다. 이 시간 동안
   코드를 작성해 F5로 미리 타워를 지어 둘 수 있습니다.
2. 카운트다운이 끝나면 적이 밀려오기 시작하고, 전투는 **멈추지 않고 실시간으로 계속** 흐릅니다.
   준비 단계로 돌아가는 일시정지 구간은 없습니다 — 코드 수정과 F5 반영도 전투 도중에 그대로
   합니다.
3. 서버 HP가 0이 되면 즉시 패배, **300초 동안 서버가 살아남으면 클리어**입니다.

## 전투 화면 UI

전투 화면은 창(1280×640) 안에서 좌→우로 **전장 · 정보 칼럼 · 코드 에디터** 3칼럼으로
구성됩니다. 전장에는 그리드와 타워·적·이펙트만 그려지고, 텍스트 정보는 모두 가운데 정보
칼럼에 모여 있습니다.

- **문제 브리핑 카드**: 스테이지에 입장하면(카운트다운 중) 화면 가운데(전장+정보 칼럼)에
  코딩테스트 문제지 형식의 카드가 뜹니다 — 문제 번호·개념·메모리 영역, 한 줄 문제 서술,
  예산과 유입 예정 적 수, 제출/채점 안내가 담겨 있습니다. **Enter**로 닫고, 전투 도중 언제든
  **Ctrl+I**로 다시 열어볼 수 있습니다.
- **정보 칼럼**: 전장과 코드 에디터 사이에 있으며 위에서부터 문제 요약, 적 구성, 함수 사전,
  전투 로그 순으로 나열됩니다.
  - **문제 요약**: 문제 번호·개념·메모리 영역을 항상 보여줍니다.
  - **적 구성**: 이 스테이지에 등장하는 적의 종류별 미니 아이콘과 "처리 n / 전체 N"이 실시간
    으로 표시됩니다. 모든 적이 스폰을 마치면 "잔여 소탕 · 생존!" 안내가 추가로 붙어 게임이
    곧 끝난다는 걸 알 수 있습니다.
  - **함수 사전**: 빌트인 함수 `build`의 사용법 문서가 항상 첫 줄에 있고, 그 아래 F5로 저장한
    코드에서 자동으로 뽑아낸 내 함수 목록이 이어집니다. 이름을 클릭하면 (`build`는 문서 카드,
    내 함수는 소스 코드 발췌가) 바로 아래에 펼쳐집니다 — 에디터에 적힌 함수명을 클릭해도
    동일하게 열립니다. (참고: `local function`으로 정의한 함수는 목록에 잡히지 않습니다.)
  - **전투 로그**: 타워 설치·크래시·워치독 재시작 같은 최근 이벤트 8줄이 표시됩니다.
- **진행 바**: 상단 HUD 바로 아래 얇은 막대가 300초 중 현재 진행률을 채워 나가고, 적이
  몰려오는 시점마다 눈금이 찍혀 있어 다음 웨이브가 언제 오는지 가늠할 수 있습니다.

## 배포 기록

개발자에게 익숙한 "배포 이력" 콘셉트로 도전 기록을 남깁니다.

- 스테이지 선택 화면의 각 항목 옆에는 지금까지의 기록이 붙습니다 — 클리어했다면
  `[클리어 · HP n]`처럼 최고 생존 HP가, 아직 못 깼다면 `[시도 n]`처럼 시도 횟수가 표시됩니다.
- 결과 화면에도 이번 판의 배포 로그 한 줄이 남습니다 — 예: "배포 #3 성공 · 서버 HP 8 잔존 ·
  타워 5기".

## 스테이지 구성

스테이지는 메모리 영역을 테마로 4구역, 구역당 3단계(총 12개)로 구성됩니다 — 뒤로 갈수록 미로
형태도 테마에 맞게 바뀝니다(코드 영역=정연한 가로 행 / 데이터 영역=블록 격자 / 스택=위에서
쌓이는 지그재그 / 힙=단편화된 조각).

| # | 테마 | 개념 | 방식 | 예산 | 보상 |
|---|------|------|------|------|------|
| 1 | 코드 영역 | 첫 타워 | 버튼(코드 자동 생성) | 200 | - |
| 2 | 코드 영역 | 전략 바꾸기 | 버튼(코드 자동 생성) | 200 | - |
| 3 | 코드 영역 | 따라 치기 | 코드 힌트(정답 그대로 옮겨 적기) | 220 | - |
| 4 | 데이터 영역 | 빈칸 채우기 | 코드 힌트(빈칸만 채우기) | 220 | 캐시 (`cache.get/set`) |
| 5 | 데이터 영역 | 변수 | 자유 코딩 | 240 | - |
| 6 | 데이터 영역 | 조건문 | 자유 코딩 (퍼즐) | 360 | 웹훅 (`on_spawn` 핸들러) |
| 7 | 스택 | 반복문 | 자유 코딩 | 280 | - |
| 8 | 스택 | 함수 | 자유 코딩 | 300 | - |
| 9 | 스택 | 복합 (반복+조건) | 자유 코딩 (퍼즐) | 320 | - |
| 10 | 힙 | 테이블 활용 | 자유 코딩 | 340 | - |
| 11 | 힙 | 종합 연습 | 자유 코딩 | 360 | - |
| 12 | 힙 | 최종 시험 | 자유 코딩 (퍼즐) | 400 | - |

1~2 스테이지는 코드를 직접 노출하지 않는 버튼(코드 자동 생성) 방식으로 시작하고, 3~4는 정답
코드를 따라 치거나 빈칸을 채우는 힌트 방식, 5~12는 변수 → 조건문 → 반복문 → 함수 → 테이블 →
종합 순서로 난이도를 올리며 완전히 자유롭게 코드를 작성합니다. "(퍼즐)"로 표시된 6·9·12는
미로와 예산이 특정 배치를 요구하는 코딩테스트형 스테이지입니다 — 사거리·경로를 고려하지
않은 순진한 배치로는 통과할 수 없습니다. 각 스테이지는 클리어 시 다음 스테이지의 잠금이
해제됩니다.

클리어 보상으로 얻은 아이템(캐시 `cache.get/set`, 웹훅 `on_spawn`)은 v0.1에서는 전투 화면에서
건설하는 **모든 타워에 자동으로 장착**됩니다(타워별 개별 장착 UI는 0.2 예정).

숨겨진 전설의 타워가 있다는 소문이... 도감에서 직접 찾아보세요.

## 튜토리얼

스테이지 1~4는 처음 플레이할 때 화면 하단에 가이드 말풍선이 뜹니다. **Enter**로 다음 설명으로
넘어가고, 언제든 **Ctrl+X**로 전체 건너뛸 수 있습니다. 설명 위주 스텝에서는 입력이 잠겨 가이드
순서대로 따라가게 되어 있습니다. 한 번 완료하거나 건너뛴 스테이지는 이후 재방문 시 다시
표시되지 않습니다.

## 비주얼·이펙트

모든 그래픽은 외부 이미지 파일 없이 코드로 직접 그립니다(폰트 제외). 네온 톤 서버실 팔레트로
전장 타일·타워(printer/compiler/sniper)·몬스터(bug/null-ptr/concat-nil)·개발자 캐릭터를
표현하고, 전투 중에는 다음과 같은 뷰 전용 이펙트가 실시간으로 붙습니다.

- 적 처치 시 폭발 파티클 + 획득 보상 숫자가 위로 떠오릅니다.
- 서버가 피격당하면 화면이 흔들리고 화면 테두리가 붉게 번쩍입니다.
- 타워를 새로 지으면 설치 지점에 플래시가 터집니다.
- 타워가 크래시하면 연기가 피어오르고, 코드 에디터 옆 개발자 아바타가 놀란 포즈를 짓습니다
  (코드를 저장하면 다시 타이핑하는 포즈로 바뀝니다).
- 전투 로그(타워 설치·크래시·워치독 재시작·널 포인터 강제 크래시 등)는 정보 칼럼 하단에
  최근 8줄이 표시됩니다(오래된 줄일수록 옅어짐).

이 이펙트들은 전투 판정 로직(`src/battle.lua`)을 전혀 바꾸지 않는 순수 뷰 레이어이며, 이전
프레임과 현재 프레임의 상태를 비교(frame-diff)해서 발동됩니다.

## 배포 패키징 (실행 파일 만들기)

```powershell
powershell -ExecutionPolicy Bypass -File tools\package.ps1
```

`dist\CodeDefense\` 폴더가 생성됩니다 — `CodeDefense.exe` 더블클릭으로 실행되며, 폴더째
복사하면 LÖVE가 설치되지 않은 PC에서도 동작합니다. 게임 데이터(`data\`)는 exe 옆에 폴더로
동봉되므로, CSV·미로·커리큘럼 파일을 수정해 나만의 스테이지를 만들 수 있습니다.
