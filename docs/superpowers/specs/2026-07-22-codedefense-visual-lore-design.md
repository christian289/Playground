# Code Defense 비주얼 에셋 + 세계관 전달 설계서

- 날짜: 2026-07-22
- 대상: `love2d-codedefense` (실시간 개편+튜토리얼 브랜치 위에 얹음)
- 전제: 전투 코어(battle/api/sandbox/tutorial)는 변경하지 않는다 — 기존 테스트 141개 무손상.
- 상태: 설계 승인됨 (구현 계획 대기)

## 1. 목표

1. AI(코드) 생성 픽셀아트 에셋으로 게임을 화려하게 — 외부 이미지·사운드 없이.
2. 세계관("보이지 않는 서버실에서 개발자가 홀로 버그와 고군분투한다")을
   게임 흐름에 자연스럽게 녹여 전달 — 인트로 컷신 + 타이틀 메뉴 항목.

## 2. 아트 디렉션 — "네온 서버실"

- **생성 방식**: 마리오 프로젝트에서 검증한 런타임 캔버스 생성 — `love.graphics` 프리미티브로
  픽셀아트를 캔버스에 그려 스프라이트시트/일러스트 이미지 생성 (nearest 필터, 로드 시 1회).
  외부 바이너리 에셋 없음 (나눔고딕 폰트 제외).
- **팔레트**: 다크 네이비/차콜 배경 + 네온 그린·시안·마젠타 포인트. 한 화면 색 6~8개로 절제.
  팔레트는 `src/art.lua` 상단 상수 테이블로 정의해 전 화면이 공유한다.
- **전장**: 벽 칸 = 서버랙 캐비닛(LED 점멸 애니메이션), 통로 = 어두운 바닥+은은한 격자,
  건설칸 = 발광 도킹 패드, 서버라인 = 맥동하는 방화벽 게이트 바.
- **타워** (16×16 → 2배 스케일, 2프레임 유휴 애니 + 발사 플래시):
  프린터 = 탄을 뱉는 미니 터렛 장비, 컴파일러 = 회전 기어 제어 유닛,
  스나이퍼 = 길쭉한 레이저 안테나.
- **몬스터** (2프레임 걷기, 피격 시 흰색 점멸 1프레임):
  bug = 빨간 딱정벌레, null-ptr = 보라 유령(물음표 문양),
  concat-nil = 주황 이중 슬라임(분열 예고 실루엣).
- **에디터 패널**: 어두운 IDE 스타일 + 상단 타이틀바("script.lua") — 오른쪽 화면이
  "개발자의 모니터"라는 연출.

## 3. 캐릭터 — "개발자" (주인공)

- **디자인**: 안경 쓴 귀여운 남성 픽셀 캐릭터. 16×16 기반(컷신용 32×32 확대판) —
  둥근 얼굴, 큰 안경(렌즈에 모니터 빛 반사 하이라이트), 후드티, 머그컵 소품.
- **포즈 3종**: 유휴(눈 깜빡임), 타이핑(손 움직임 2프레임), 놀람(안경 번쩍).
- **등장 지점**:
  1. 인트로 컷신 주역.
  2. 타이틀 화면 — 서버실 배경에 앉아 있는 뒷모습 + 모니터 불빛.
  3. **에디터 타이틀바 구석의 미니 아바타** — 평소 유휴, F5 저장 성공 시 타이핑 모션(1초),
     타워 크래시 발생 시 놀람 표정(1초). 코드를 치는 주체가 이 개발자라는 감각을 상시 유지.

## 4. 세계관 전달

### 4.1 인트로 컷신 (`states/intro.lua`) — 개발자의 애환 4장면

각 장면: 코드 생성 픽셀 일러스트(960×420 영역) + 타이프라이터 텍스트(하단).
Enter = 다음 장면(타이핑 중이면 즉시 전체 표시), ESC = 전체 스킵.

1. **[지상 — 화려한 서비스]** 사람들이 스마트폰 앱을 쓰며 웃는 밝은 거리.
   > "모두가 매일 쓰는 서비스. 하지만 이것이 어디에서 돌아가는지, 아는 사람은 없다."
2. **[지하 — 서버실]** 어두운 지하, 줄지어 깜빡이는 서버랙. 구석에 모니터 불빛에 비친
   안경 쓴 개발자 혼자.
   > "보이지 않는 곳. 새벽 세 시의 서버실. 여기, 한 명의 개발자가 있다."
3. **[장애 발생]** 모니터가 빨갛게 물들고 서버에서 버그들이 기어나온다. 알림이 쏟아진다.
   > "버그는 예고 없이 온다. 서비스는 멈추면 안 된다. 아무도 이 싸움을 모른다."
4. **[결의]** 개발자가 안경을 고쳐 쓰고 키보드에 손을 올린다. 화면에 커서가 깜빡인다.
   > "알아주는 이 없어도, 그의 무기는 단 하나 — 코드다."

- **첫 실행 시 1회 자동 재생**: `progress.intro_seen` 저장 (기존 세이브에 필드 없으면 보강).
  재생 후 타이틀로.
- 장면 데이터는 `states/intro.lua` 안의 배열(일러스트 함수 참조 + 텍스트)로 정의.

### 4.2 타이틀 메뉴

- 항목: `게임 시작 / 세계관 / 종료` (↑↓ + Enter, 기존 "Enter로 시작" 대체).
- "세계관" = 인트로 재생 (끝나면 타이틀 복귀).
- 타이틀 화면 배경: 서버실 아트 + 개발자 뒷모습 + 게임 로고 픽셀 타이포.

### 4.3 결과 화면 여운 문구

- 클리어: "오늘도 서비스는 무사히 돌아간다. 아무 일 없었다는 듯이."
- 패배: "서버가 내려갔다. 하지만 개발자는 다시 일어선다."
- 기존 결과 정보(보상 등) 아래 작은 폰트로 추가.

## 5. 이펙트 (`src/particles.lua`)

- 경량 자체 파티클 시스템: `spawn(kind, x, y, opts)`, `update(dt)`, `draw(offsetX, offsetY)`.
- 종류: 타격 스파크, 처치 픽셀 폭발 + `+N` 보상 플로트 텍스트, 타워 크래시 연기(지속·크래시
  해제 시 중단), 설치 등장 플래시, 서버 피격 시 화면 가장자리 빨간 플래시 + 미세 셰이크(0.2초,
  진폭 3px), 차지샷 총알 글로우(차지량 비례 크기·밝기).
- **상한 400개** — 초과 시 오래된 것부터 제거 (성능 가드).
- 전부 뷰 전용: battle 코어 상태를 읽기만 하며(적 사망·크래시·설치는 프레임 간 상태 비교로
  감지), 시뮬 결정론에 영향 없음.

## 6. 아키텍처

```
신규: src/art.lua        ← 팔레트 상수 + 시트/배경/일러스트/아바타 생성 (love.graphics 의존)
신규: src/particles.lua  ← 파티클 시스템 (로직은 헤드리스 테스트 가능 — love 의존은 draw만)
신규: states/intro.lua   ← 컷신 (장면 배열 + 타이프라이터 + 스킵)
변경: main.lua           ← art 로드, 첫 실행 시 intro 분기
변경: states/title.lua   ← 메뉴 3항목 + 배경 아트
변경: states/play.lua    ← 그리기 교체(배경/타워/적/총알/아바타/파티클/셰이크), 로직 불변
변경: states/result.lua  ← 여운 문구 + 톤
변경: states/stageselect.lua ← 팔레트 톤만
변경: src/progress.lua   ← intro_seen 보강
불변: battle/api/sandbox/tutorial/editor 코어 — 기존 테스트 141개 무손상
```

- art.lua는 `art.load()` 1회 생성 (love.load에서), 모듈 테이블로 이미지/쿼드/그리기 헬퍼 노출.
- play의 이펙트 발동은 프레임 간 비교(이전 적 목록 vs 현재, 타워 crashed 전이, 타워 수 증가,
  serverHP 감소)로 감지 — battle에 훅 추가 없음.

## 7. 테스트·검증

- 신규 헤드리스 테스트: 파티클 수명·상한·제거 로직(`test_particles.lua`),
  intro 장면 진행 로직(장면 인덱스·타이프라이터 완료·스킵 — 그리기 제외),
  progress.intro_seen 저장/보강.
- 기존 141개 무손상 (코어 불변이므로).
- 시각 검증: 스크린샷 하네스로 인트로 4장면·타이틀·전투(파티클 발동 포함) 캡처 확인.
- 부팅 스모크.

## 8. 범위 제외

- 사운드(명시적 제외), 외부 AI 이미지 도구 연동, 스테이지별 배경 변주, 컷신 애니메이션
  (장면은 정지 일러스트 + 텍스트), 다국어.
